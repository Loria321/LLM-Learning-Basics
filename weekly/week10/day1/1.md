## 一、核心概念精讲（必学基础）
向量数据库的所有能力，都围绕这3个核心概念展开，我用最通俗的语言解释：

### 1. 向量存储
- **定义**：专门存储**高维向量（Embedding）** 的存储方式，不存储文本、图片等原始数据，只存储AI模型将数据转化后的**数字数组**（比如一段文字转成1536维的数字列表）。
- **核心特点**：
  ✅ 存储高维数据（维度通常128~4096，甚至更高）；
  ✅ 支持批量写入、增量更新；
  ✅ 区别于传统数据库（传统库存数字、文本，不优化高维向量）。

### 2. 相似性检索
向量数据库**最核心的功能**（也是和普通数据库最大的区别）：
- **不是精确匹配**：传统数据库查`关键词=张三`，向量数据库查**和目标数据最相似的内容**；
- **核心算法**：余弦相似度、欧氏距离、点积（判断两个向量的相似程度）；
- **关键技术**：ANN（近似最近邻搜索）→ 大数据量下，用近似结果换检索速度（100%精确搜索太慢，无法商用）。

### 3. 索引
向量数据库的**加速引擎**，解决「高维向量检索极慢」的问题：
- 无索引：10万条向量检索需要几秒；有索引：毫秒级完成；
- 主流索引算法：HNSW（高精度）、IVF（大容量）、PQ（降维压缩）；
- 核心作用：平衡**检索速度**和**召回精度**，是向量数据库的核心技术。

## 二、主流向量数据库/工具对比（Chroma / FAISS / Milvus）
直接给你**工程化对比表**，一眼看懂三者的定位和差异：

| 对比维度         | Chroma                  | FAISS                   | Milvus                  |
|------------------|-------------------------|-------------------------|-------------------------|
| **核心定位**     | 轻量级嵌入式向量数据库  | 高性能向量检索算法库    | 企业级分布式向量数据库  |
| **部署方式**     | 无服务器/内存/本地文件  | 本地算法库（无服务）| 分布式集群/单机         |
| **开源协议**     | 完全开源（MIT）| 完全开源（MIT）| 完全开源（Apache）|

| **性能**         | 中小数据量（万级）| 超高性能（百万级）| 企业级（亿级高并发）|

### 核心总结（必记）
1. **Chroma**：最轻量，**专为AI开发/小项目设计**，不用部署服务，开箱即用；
2. **FAISS**：不是数据库！是纯算法库，性能天花板，但没有存储、管理功能；
3. **Milvus**：企业级生产工具，功能最全，但太重，不适合入门学习。

### 2. 快速上手（Python 实操代码）
#### 第一步：安装
```bash
pip install chromadb
```

#### 第二步：核心操作（存储向量 + 相似性检索）
```python
import chromadb

# 1. 初始化客户端（本地模式，自动创建文件存储）
client = chromadb.PersistentClient(path="./chroma_db")

# 2. 创建集合（相当于数据库的表，存储向量）
collection = client.create_collection(name="my_first_collection")

# 3. 添加数据（自动生成向量，无需手动处理）
collection.add(
    documents=["我喜欢吃火锅", "今天天气晴朗", "向量数据库很有用"],
    metadatas=[{"type": "food"}, {"type": "weather"}, {"type": "tech"}],
    ids=["id1", "id2", "id3"]
)

# 4. 相似性检索（核心功能！查最相似的2条数据）
results = collection.query(
    query_texts=["美食推荐"],
    n_results=2
)

# 打印结果
print("检索结果：", results["documents"])
```

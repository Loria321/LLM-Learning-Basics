t-SNE是特征可视化的核心工具（尤其适合高维文本特征），和之前学的PCA不同：PCA是**线性降维**，优先保留全局信息；t-SNE是**非线性降维**，更关注局部结构，能更好地展示同类样本的聚类效果，是特征可视化的首选方法。

下面我会先讲解t-SNE的核心概念，再完成完整的可视化实操，最后分析聚类效果并优化特征提取参数。

---

## 一、t-SNE核心概念（适合可视化的关键原因）
### 1. t-SNE vs PCA（核心差异）
| 特性                | PCA（主成分分析）| t-SNE（t分布随机邻域嵌入）|
|---------------------|-----------------------------|-----------------------------|
| 降维方式            | 线性降维（全局结构）| 非线性降维（局部结构）|
| 核心目标            | 保留数据的全局方差（信息）| 保留样本间的局部相似性      |
| 适用场景            | 数据压缩、特征降维          | 高维特征可视化（2D/3D）|
| 计算效率            | 快（线性计算）| 慢（非线性迭代）|
| 结果稳定性          | 稳定（参数少）| 不稳定（受参数影响大）|

### 2. t-SNE关键参数（影响可视化效果）
- `n_components`：降维后的维度（2或3，仅用于可视化）；
- `perplexity`：困惑度（核心参数），控制“近邻样本数”，推荐值5-50（小样本设5-10，大样本设20-50）；
- `learning_rate`：学习率，推荐值100-1000（过小会导致样本扎堆，过大导致分散）；
- `random_state`：随机种子，固定后结果可复现（否则每次运行可视化结果不同）。

```python
import jieba
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.manifold import TSNE
from sklearn.feature_selection import SelectKBest, mutual_info_classif

# ====================== 1. 数据准备（复用扩充的校园问答样本） ======================

    "教务系统选课失败是什么原因，该怎么解决",

# 1=图书馆主题（20篇）
library_qa = [
    "图书馆的图书可以借阅多久，逾期会有什么处罚",
    "图书馆的自习室需要提前预约吗，预约方式是什么",
    "如何查询图书馆有没有我需要的专业书籍",
    "借阅的图书快到期了，能不能在线续借，续借多久",
    "图书馆的电子资源怎么访问，需要校园网吗",
    "不小心把借阅的图书弄丢了，该怎么赔偿",
    "图书馆的工具书可以外借吗，还是只能在馆内阅读",
    "自习室预约成功后，迟到多久会取消资格",
    "图书馆的复印打印服务在哪里，怎么收费",
    "校外人员可以进入学校图书馆吗，需要什么证件",
    "借阅的图书有破损，还书的时候会被罚款吗",
    "图书馆的数据库资源可以下载论文吗，有没有版权限制",
    "自习室里可以使用笔记本电脑吗，有没有电源插座",
    "如何办理图书馆的读者证，需要准备什么材料",
    "图书馆的新书多久更新一次，怎么关注新书通知",
    "借取的图书想转借给同学，可以吗，需要办理手续吗",
    "图书馆的闭馆时间是什么时候，周末开放吗",
    "忘记带校园卡，能不能用身份证进入图书馆",
    "图书馆的专题书架在哪里，怎么快速找到",
    "电子图书可以下载到本地吗，支持什么格式"
]

# 2=请假主题（20篇）
leave_qa = [
    "我需要请假三天，请假流程是什么样的",
    "请假需要提交什么材料，多久能审批通过",
    "病假需要提供医院的诊断证明吗，复印件可以吗",

    "研究生请假需要导师和辅导员双重审批吗",

    "实习期间需要请假，应该找学校还是实习单位审批",

# 整合数据和标签
texts = course_qa + library_qa + leave_qa
labels = [0]*20 + [1]*20 + [2]*20  # 0=选课，1=图书馆，2=请假
label_names = ["选课", "图书馆", "请假"]
colors = ["#FF6B6B", "#4ECDC4", "#45B7D1"]  # 三类主题的配色

# 中文预处理函数（分词+停用词过滤）
def preprocess_text(text, stop_words=None):
    words = jieba.lcut(text.strip())
    if stop_words:
        words = [w for w in words if w not in stop_words and len(w) > 0]
    return " ".join(words)

# 预设停用词列表（校园场景）
stop_words = ["的", "地", "得", "我", "你", "他", "她", "它", "什么", "如何", "请问", "吗", "呢", "这", "那", "是", "有", "在", "了", "就", "都"]
processed_texts = [preprocess_text(t, stop_words) for t in texts]

# ====================== 2. 提取TF-IDF特征（基础版） ======================
# 基础版TF-IDF（仅分词+停用词，无特征选择）
tfidf_basic = TfidfVectorizer()
features_basic = tfidf_basic.fit_transform(processed_texts).toarray()
print(f"基础版TF-IDF特征维度：{features_basic.shape[1]}")

# ====================== 3. t-SNE降维（2D/3D） ======================
def tsne_visualize(features, labels, n_components=2, perplexity=30, title=""):
    """
    t-SNE可视化函数
    Args:
        features: 高维特征矩阵
        labels: 样本标签
        n_components: 2/3（2D/3D）
        perplexity: t-SNE困惑度
        title: 图表标题
    """
    # t-SNE降维
    tsne = TSNE(
        n_components=n_components,
        perplexity=perplexity,
        learning_rate=200,
        random_state=42,
        init="pca"  # 用PCA初始化，提升稳定性
    )
    features_tsne = tsne.fit_transform(features)
    
    # 创建画布
    plt.figure(figsize=(10, 8))
    plt.rcParams["font.sans-serif"] = ["SimHei"]  # 显示中文
    plt.rcParams["axes.unicode_minus"] = False    # 显示负号
    
    # 绘制2D可视化
    if n_components == 2:
        for label in [0, 1, 2]:
            mask = (np.array(labels) == label)
            plt.scatter(
                features_tsne[mask, 0],
                features_tsne[mask, 1],
                c=colors[label],
                label=label_names[label],
                alpha=0.7,
                s=60,
                edgecolors="white",
                linewidth=0.5
            )
        plt.xlabel("t-SNE维度1", fontsize=12)
        plt.ylabel("t-SNE维度2", fontsize=12)
    
    # 绘制3D可视化
    elif n_components == 3:
        ax = plt.subplot(111, projection="3d")
        for label in [0, 1, 2]:
            mask = (np.array(labels) == label)
            ax.scatter(
                features_tsne[mask, 0],
                features_tsne[mask, 1],
                features_tsne[mask, 2],
                c=colors[label],
                label=label_names[label],
                alpha=0.7,
                s=60,
                edgecolors="white",
                linewidth=0.5
            )
        ax.set_xlabel("t-SNE维度1", fontsize=12)
        ax.set_ylabel("t-SNE维度2", fontsize=12)
        ax.set_zlabel("t-SNE维度3", fontsize=12)
    
    # 图表样式
    plt.title(title, fontsize=14, fontweight="bold", pad=20)
    plt.legend(fontsize=11, loc="best")
    plt.grid(alpha=0.3)
    plt.tight_layout()
    plt.show()
    
    return features_tsne

# 3.1 基础版TF-IDF的2D可视化
print("\n=== 基础版TF-IDF特征2D可视化 ===")
tsne_2d_basic = tsne_visualize(
    features_basic,
    labels,
    n_components=2,
    perplexity=30,
    title="基础版TF-IDF特征 t-SNE 2D可视化（校园问答三类主题）"
)

# 3.2 基础版TF-IDF的3D可视化
print("\n=== 基础版TF-IDF特征3D可视化 ===")
tsne_3d_basic = tsne_visualize(
    features_basic,
    labels,
    n_components=3,
    perplexity=30,
    title="基础版TF-IDF特征 t-SNE 3D可视化（校园问答三类主题）"
)

# ====================== 4. 优化特征提取参数（提升聚类效果） ======================
# 优化方向：1. TF-IDF加入ngram；2. 互信息法特征选择
# 4.1 优化版TF-IDF（ngram_range=(1,2)：单字+双词，捕捉更多语义）
tfidf_optimized = TfidfVectorizer(ngram_range=(1, 2))
features_optimized_raw = tfidf_optimized.fit_transform(processed_texts).toarray()

# 4.2 互信息法筛选前100个高相关特征
skb = SelectKBest(mutual_info_classif, k=100)
features_optimized = skb.fit_transform(features_optimized_raw, labels)
print(f"\n优化版TF-IDF特征维度（ngram+互信息筛选）：{features_optimized.shape[1]}")

# 4.3 优化版特征的2D可视化
print("\n=== 优化版TF-IDF特征2D可视化 ===")
tsne_2d_optimized = tsne_visualize(
    features_optimized,
    labels,
    n_components=2,
    perplexity=30,
    title="优化版TF-IDF特征（ngram+互信息） t-SNE 2D可视化"
)

# ====================== 5. 聚类效果量化分析（可选） ======================
from sklearn.metrics import silhouette_score
# 轮廓系数：[-1,1]，越接近1表示聚类效果越好
sil_basic = silhouette_score(tsne_2d_basic, labels)
sil_optimized = silhouette_score(tsne_2d_optimized, labels)
print(f"\n=== 聚类效果量化分析 ===")
print(f"基础版TF-IDF特征轮廓系数：{sil_basic:.4f}")
print(f"优化版TF-IDF特征轮廓系数：{sil_optimized:.4f}")
```

## 三、可视化结果解读与聚类效果分析
### 1. 基础版TF-IDF特征可视化结果（预期）
- **聚类效果**：三类主题（选课/图书馆/请假）有一定聚类趋势，但边界模糊，部分样本交叉重叠（比如“选课”和“请假”的部分样本混在一起）；
- **核心问题**：
  1. TF-IDF仅捕捉单字特征，无法识别“选修课”“自习室”等双词的语义关联；
  2. 未做精细化特征选择，仍有少量冗余特征干扰聚类；
  3. 轮廓系数约0.2-0.3（聚类效果一般）。

### 2. 优化版TF-IDF特征可视化结果（预期）
- **聚类效果**：三类主题形成明显的“簇状分布”，同类样本紧密聚集，异类样本边界清晰，几乎无交叉；
- **优化效果**：
  1. ngram=(1,2)捕捉了“选修课”“自习室”“请假条”等双词特征，语义表达更完整；
  2. 互信息法筛选出前100个高相关特征，剔除冗余噪音，特征纯度更高；
  3. 轮廓系数提升至0.4-0.5（聚类效果显著提升）。

### 3. t-SNE参数对可视化的影响（关键调优）
- **perplexity**：若样本数60，设为10-30最佳；过小（<5）会导致聚类碎片化，过大（>50）会导致聚类模糊；
- **learning_rate**：设为200-500最佳；过小会导致所有样本扎堆，过大导致样本过度分散；
- **random_state**：固定为42，确保每次运行结果一致，便于对比优化效果。

## 四、特征提取参数优化指南（核心结论）
| 优化方向                | 具体参数调整                          | 效果提升点                          |
|-------------------------|---------------------------------------|-------------------------------------|
| 语义表达增强            | TF-IDF的`ngram_range=(1,2)`           | 捕捉双词特征，提升语义完整性        |
| 冗余特征剔除            | 互信息法`SelectKBest(k=100)`          | 保留高相关特征，减少噪音干扰        |
| 停用词过滤              | 扩充停用词列表（如“可以”“需要”）| 剔除无意义词汇，提升特征纯度        |
| t-SNE参数调优           | `perplexity=30`+`learning_rate=200`   | 优化可视化效果，凸显聚类结构        |

---

### 总结
1. **t-SNE是高维文本特征可视化的最优选择**：非线性降维能更好展示同类样本的局部聚类效果，远超PCA的可视化表现；
2. **基础TF-IDF的聚类效果有限**：仅靠单字特征和简单停用词过滤，无法满足精细化聚类需求；
3. **参数优化显著提升聚类效果**：加入ngram捕捉多词语义、互信息法筛选高相关特征，能让同类样本紧密聚集，异类样本边界清晰；
4. **量化指标辅助分析**：轮廓系数（silhouette_score）可客观评估聚类效果，数值越高说明特征的区分能力越强。

通过这套可视化分析流程，你可以直观判断特征提取的效果，针对性优化参数，让TF-IDF特征更适配后续的分类/聚类模型。
